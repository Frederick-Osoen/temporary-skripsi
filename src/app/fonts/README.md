Font self-hosted (subset latin, variable wght), diambil dari paket npm Fontsource 5.3.0:
- inter.woff2 (Inter), plus-jakarta-sans.woff2 (Plus Jakarta Sans): dashboard admin
- unbounded.woff2 (Unbounded), geologica.woff2 (Geologica): situs publik

Semuanya berlisensi SIL Open Font License 1.1 (bebas dipakai dan disematkan di situs).
Self-host dipilih supaya build tidak bergantung pada fonts.googleapis.com dan font termuat dari domain sendiri.
